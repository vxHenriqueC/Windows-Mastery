# ⌨️ Windows Run Commands (Win + R)

The **Run dialog** (`Win + R`) provides quick access to Windows tools, settings, administrative consoles, and Control Panel applets without navigating through menus.

---

# 📚 Run Command Reference

| Command | Description | Category | Admin |
|---------|-------------|:--------:|:----:|
| `appwiz.cpl` | Opens the Programs and Features window to uninstall or modify installed applications. | Control Panel | ❌ |
| `control` | Opens the Control Panel. | Control Panel | ❌ |
| `control printers` | Opens the Devices and Printers window. | Devices | ❌ |
| `optionalfeatures` | Opens Windows Features to enable or disable optional components. | Windows | ✅ |
| `ms-settings:` | Opens the Windows Settings app. | Settings | ❌ |
| `cmd` | Opens Command Prompt. | Terminal | ❌ |
| `powershell` | Opens Windows PowerShell. | Terminal | ❌ |
| `wt` | Opens Windows Terminal. | Terminal | ❌ |
| `regedit` | Opens the Registry Editor. | Administration | ✅ |
| `gpedit.msc` | Opens the Local Group Policy Editor. | Administration | ✅ |
| `services.msc` | Opens the Services management console. | Administration | ✅ |
| `taskmgr` | Opens Task Manager. | Administration | ❌ |
| `devmgmt.msc` | Opens Device Manager. | Hardware | ✅ |
| `diskmgmt.msc` | Opens Disk Management. | Storage | ✅ |
| `eventvwr.msc` | Opens Event Viewer. | Troubleshooting | ✅ |
| `compmgmt.msc` | Opens Computer Management. | Administration | ✅ |
| `lusrmgr.msc` | Opens Local Users and Groups (Pro/Enterprise editions). | Users | ✅ |
| `secpol.msc` | Opens Local Security Policy (Pro/Enterprise editions). | Security | ✅ |
| `wf.msc` | Opens Windows Defender Firewall with Advanced Security. | Security | ✅ |
| `resmon` | Opens Resource Monitor. | Monitoring | ❌ |
| `perfmon` | Opens Performance Monitor. | Monitoring | ✅ |
| `msconfig` | Opens System Configuration. | Startup | ✅ |
| `msinfo32` | Opens System Information. | System | ❌ |
| `dxdiag` | Opens the DirectX Diagnostic Tool. | Diagnostics | ❌ |
| `cleanmgr` | Opens Disk Cleanup. | Maintenance | ❌ |
| `mrt` | Opens the Microsoft Malicious Software Removal Tool. | Security | ❌ |
| `ncpa.cpl` | Opens Network Connections. | Networking | ❌ |
| `firewall.cpl` | Opens Windows Defender Firewall settings. | Security | ❌ |
| `inetcpl.cpl` | Opens Internet Options. | Network | ❌ |
| `control folders` | Opens File Explorer Options. | File Explorer | ❌ |
| `shell:startup` | Opens the current user's Startup folder. | Shell | ❌ |
| `shell:common startup` | Opens the Startup folder for all users. | Shell | ✅ |
| `shell:downloads` | Opens the Downloads folder. | Shell | ❌ |
| `shell:desktop` | Opens the Desktop folder. | Shell | ❌ |
| `shell:documents` | Opens the Documents folder. | Shell | ❌ |
| `shell:sendto` | Opens the SendTo folder. | Shell | ❌ |
| `shell:recent` | Opens the Recent Items folder. | Shell | ❌ |
| `shell:AppsFolder` | Opens the Applications folder containing installed apps. | Shell | ❌ |
| `explorer` | Opens File Explorer. | File Explorer | ❌ |
| `notepad` | Opens Notepad. | Applications | ❌ |
| `calc` | Opens Calculator. | Applications | ❌ |
| `mspaint` | Opens Microsoft Paint. | Applications | ❌ |
| `snippingtool` | Opens the Snipping Tool. | Applications | ❌ |
| `osk` | Opens the On-Screen Keyboard. | Accessibility | ❌ |
| `magnify` | Opens Magnifier. | Accessibility | ❌ |
| `narrator` | Opens Narrator. | Accessibility | ❌ |
